> ### 1. 通过命令行查看系统资源（间接方法）
> 
> macOS的命令行工具集（如`sysctl`、`powermetrics`等）主要用于查看**系统状态**，而直接获取CPU核心的**实时温度**通常不是一个内置且简单命令能直接提供的功能。
> 
> *   **查看CPU频率和核心信息：**
>     你可以使用 `sysctl` 来查看系统级别的CPU信息，但这通常是电压、频率等，而不是温度。
>     ```bash
>     sysctl -n machcup.cpu.brand_string
>     ```
> 
> *   **使用 `powermetrics` (推荐尝试)：**
>     这是苹果提供的用于性能测量的工具。你可以尝试查看功耗和一些底层传感器数据。
>     ```bash
>     sudo powermetrics --samplers cpu_power,temp
>     ```
>     **注意：**
>     1.  你需要使用 `sudo` 权限。
>     2.  这个命令会输出大量信息，你需要仔细查找与 `temp` 相关的部分。
>     3.  这个命令的输出格式可能会随着macOS版本更新而变化。
> 
> ### 2. 使用第三方工具或软件（更可靠的方法）
> 
> 如果你想获得准确、易读的温度信息，最可靠的方法是使用专门的**第三方系统监控工具**，而不是纯命令行。这些工具通常会封装了底层硬件信息，提供图形界面或更友好的命令行输出。
> 
> 在Mac用户社区中，用户经常推荐使用：
> 
> *   **iStat Menus / TG Pro (GUI工具):** 这些是收费的、广受好评的系统监控工具，它们会将温度信息直接集成到菜单栏，最方便查看。
