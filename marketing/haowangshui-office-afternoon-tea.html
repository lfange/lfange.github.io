好望水进办公室下午茶策划案

作业一：从 价值 / 体验 / 关系资产 三个维度做策划。

一、背景与核心命题

好望水以「望」系列东方植物饮料（望山楂、望桃花、望杏福、望梅好）立足新中式赛道，已有的强势场景集中在聚餐佐餐、婚礼喜宴、节令送礼。而办公室下午茶是一个被咖啡、奶茶、无糖气泡水占据的高频日常场景，且正在经历「健康化 + 悦己化」的消费迁移——这与好望水「真果汁、东方植物」的产品心智天然契合。

本策划的核心命题：不是「送一批饮料进办公室」，而是借一场下午茶，完成一次「场景渗透 + 人群渗透 + 关系沉淀」。

检验标准写在最前面：活动结束一周后，好望水在这栋写字楼里留下了什么——是只剩下空瓶子，还是留下了用户、内容和一份可持续的企业合作关系。

二、人群与场景洞察

洞察点内容
时间15:00–16:00 是打工人的能量低谷 + 摸鱼高峰，情绪上需要「喘口气 + 一点甜头」
现有选择痛点咖啡提神但加剧焦虑、影响晚间睡眠；奶茶快乐但有含糖负罪感；无糖气泡水健康但「无聊」
场景空位有真果汁口感 + 气泡爽感 + 低负担 + 有情绪价值 的下午茶选项
社交机制下午茶天然是拼单文化、茶水间社交的载体；行政 / HR 需要低成本、高感知的员工关怀物料
情绪洞察办公室语境关键词是「盼下班、望加薪、求不加班」——「望」恰好是品牌自带的语言资产

三、维度一：价值 —— 给用户一个「值得」的理由

顾客感知价值 = 功能价值 + 情绪价值 + 社交价值。

价值层次用户获得好望水的做法
功能价值好喝、解腻、无负担主推望山楂绑定「午饭后的解腻时刻」；气泡 + 真果汁口感；强调干净配料表
情绪价值被祝福、被治愈的悦己感激活「望」的祝福语义：望杏福≈幸福、望梅好≈美好；定制打工人文案「望你准点下班」「望你方案一次过」，把一瓶饮料变成一句祝福
社交价值茶水间的社交货币高颜值新中式包装出片；瓶身话题 + 拼单分享的由头

对企业方（行政 / HR）的价值：一次预算可控、执行全包、员工拍照自发传播的员工关怀方案——帮行政完成一次「低成本、高感知」的团建动作。

对品牌的价值：

  • 从「佐餐场景」向「日常办公场景」渗透，提升购买频次
  • 高浓度触达都市白领核心目标人群
  • 每一次试饮与 UGC 都是品牌资产的复利

四、维度二：体验 —— 设计一段有峰值、有终值的旅程

按「预热 → 到场 → 参与 → 离场 → 延续」全旅程设计，运用峰终定律：峰值决定「被记住」，终值决定「被带走」。

1. 预热期（D-3 ~ D-1）：制造「被邀请感」

  • 电梯 / 茶水间悬念海报：「明天 15:00，望你来」
  • 行政内部群预告 + 工位桌面小卡片

2. 到场（15:00–15:15）：反差感即记忆点

  • 「望水补给站」快闪装置：原木 + 暖光 + 东方纹样的新中式美学，与办公室冷色调形成视觉反差，天然拍照点
  • 全口味冰镇试饮矩阵，附「盲猜口味」小互动

3. 参与（15:15–16:00）：制造峰值时刻 ⭐

  • 「望愿签」抽签筒：签文全部是打工人祝福梗（「望你周二快乐」「望你会议提前结束」）；隐藏签「望你暴富」抽中者整箱好望水寄到家——制造尖叫点，也是天然传播素材
  • 定制祝福贴纸：现场手写祝福贴纸贴上瓶身送给同事——把「送水」变成「送祝福」，瓶子在工位上成为一周的延伸曝光
  • 打卡发布：拍照发布小红书 / 朋友圈带话题 #办公室望一望#，凭截图领周边

4. 离场（16:00–16:30）：设计终值时刻

  • 人手一份「望你好运」伴手礼：1 瓶 + 复购优惠券卡
  • 现场抽取 3 位「望水推荐官」，送整箱装

5. 延续期（D+1 ~ D+7）

  • 话题页 UGC 征集，官方账号精选转发
  • 扫码入群领「下周摸鱼水」券，把一次试饮转化为下一次复购

五、维度三：关系资产 —— 活动结束，关系才开始

单场活动是费用，能沉淀下来的关系才是资产。本策划沉淀四类关系资产：

1. 用户资产（C 端）

试饮 → 扫码加入企微社群「望水摸鱼群」→ 小程序会员 → 电商 / 外卖复购。优惠券设计为「第二件半价 / 整箱券」，同时拉动复购与分享。

2. 企业关系资产（B 端）—— ROI 的真正来源

目标是进入行政的「下午茶供应商名录」，把一场活动变成一条渠道：

活动合作 → 月度下午茶常态化 → 中秋 / 年会礼盒团购 → 员工内购价

一场活动的投入产出，要用后续 12 个月的企业采购来计算。

3. 内容资产

  • 授权后的 UGC 素材库（用于官方账号二次传播）
  • 话题标签 #办公室望一望# 的持续沉淀
  • 活动 SOP 沉淀为可复制的「办公室巡展标准包」，下一场的边际成本大幅下降

4. 生态与渠道资产

  • 写字楼物业合作：固定点位巡展
  • 楼内便利店 / 自动售卖机的陈列联动
  • 与周边轻食店联名「望水 + 轻食套餐」
  • KOC 资产：从员工中发展「望水推荐官」，长期发布内容享专属权益

三维度小结

价值决定用户「来不来」，体验决定用户「记不记得住」，关系资产决定品牌「留下多少」。 三者层层递进，缺一不可。

六、执行排期

阶段时间关键动作产出
预热期D-3 ~ D-1海报 + 桌卡投放，行政预告到场预期人数
活动日D0 14:30–16:30补给站快闪 + 试饮 + 望愿签 + 打卡试饮 / UGC / 入群
长尾期D+1 ~ D+7UGC 征集、优惠券核销提醒复购数据
常态化D+30行政回访，推进月度合作 / 团购企业采购订单

七、资源与预算框架（以 100–150 人公司单场为例）

项目内容预算占比
样品全口味试饮 + 伴手礼 + 隐藏奖，约 300–400 瓶（按成本价核算）~40%
装置物料快闪补给站、海报、桌卡、贴纸（可复用摊薄）~30%
周边礼品瓶起子 / 贴纸包 / 帆布袋，打卡兑换~15%
人员执行现场督导 + 兼职~15%

预算随公司规模伸缩；核心原则是样品和体验物料优先，砍预算不砍峰值体验。

八、效果衡量（KPI）

维度指标参考目标
触达现场参与率≥ 60% 员工
转化试饮 → 入群率≥ 30%
转化优惠券 7 日核销率≥ 15%
内容话题下 UGC 数量≥ 50 条
关系新增企微 / 会员≥ 80 人
关系行政复购 / 团购意向≥ 3 家

复盘口径：单场获客成本 vs 电商投放获客成本对比——若低于投流成本且沉淀了 B 端渠道，即可复制推广。
